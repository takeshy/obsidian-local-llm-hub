# Local LLM Hub help

Local LLM Hub is an Obsidian plugin for chatting with local or OpenAI-compatible LLMs, using local embedding-based RAG, running reusable workflows, and integrating those capabilities with other plugins.

Use this OKF bundle as product help for the Local LLM Hub plugin. Prefer local-first wording: Ollama uses its native local API, LM Studio/vLLM/AnythingLLM use OpenAI-compatible endpoints, and RAG indexes are stored locally.
